## 规则阈值口径提醒（被验证的引擎行为）

| 规则 | 阈值 | 命中口径 | 严重度分档 |
|---|---|---|---|
| R1 三表勾稽 | 3% | 差异率 **严格 >** 3% | >20% 高 / >5% 中 / 否则低 |
| R2 账税一致性 | 5% | 差异率 **严格 >** 5% | >15% 高 / >5% 中 / 否则低 |
| R3 所得税匹配 | 10% | 差异率 **严格 >** 10% | >25% 高 / >10% 中 / 否则低 |
| R4 发票-申报比对 | 5% | 差异率 **严格 >** 5% | >15% 高 / >5% 中 / 否则低 |
| R5 现金流勾稽 | 收现比 0.7–1.3 | **严格** <0.7 或 >1.3 | <0.5 或 >1.5 高 / 命中即中 / 否则低 |
| R6 社保个税匹配 | 10% | 差异率 **严格 >** 10% | >25% 高 / >10% 中 / 否则低 |

健康分 = 100 − 规则扣分（高 30 / 中 20 / 低 10）− 申报扣分（逾期 12 / 临期 4），下限截断为 0；等级：绿 ≥ 90，黄 60–89，红 < 60。

## 用例明细

| # | 企业 | 验证场景 | 预期命中规则（严重度） | 预期等级 | 预期健康分 | 预期逾期/临期 | 验证的规则点 |
|---|---|---|---|---|---|---|---|
| 1 | 边界精密 | 差异率恰好 = 5% 阈值 | 无（R2=5.0%、R4=5.0% 均不命中） | 绿 | 100 | 0 / 0 | R2、R4 阈值为严格 `>` 而非 `>=`，恰好等于阈值不命中（含浮点等值：`100/2000 === 0.05`） |
| 2 | 临界智造 | 差异率 4.9% 不命中（近失） | 无（R2=4.9%<5%；R6=10.0% 恰好等于阈值不命中） | 绿 | 96（−4 临期） | 0 / 1（印花税，距截止 3 天） | 阈值下方近失不命中；R6 阈值同为严格 `>` 口径；临期状态机（daysToDue ≤ 3）与临期扣分 |
| 3 | 恒迅科技 | 收现比临界 + R3 命中 | R3（12%，中） | 黄 | 80（−20） | 0 / 0 | R5 下界为严格 `<`：收现比恰好 0.70 不命中；R3 在 10% 上方命中且严重度分档正确（10%<12%<25% → 中，扣 20） |
| 4 | 曜石集团 | 极端红色：单家命中 ≥4 条规则 | R1（50%，高）、R2（20%，高）、R4（20%，高）、R5（收现比 0.40，高）、R6（33.3%，高）；R3 不命中 | 红 | 0（100−30×5=−50，截断为 0） | 2 / 1（增值税、个税各逾期 5 天；印花税临期） | 多规则扣分叠加与健康分 0 分下限截断；引擎能识别唯一不命中的 R3；R5 高档（<0.5 → 高）；逾期+临期混合状态 |
| 5 | 安澜医药 | 完美绿色：全部合规 | 无 | 绿 | 100 | 0 / 0 | 零扣分基准；含分红的三表勾稽（净利润 600 = 未分配利润变动 540 + 分红 60）；「未到期」不误判为临期 |
| 6 | 宏宇建设 | 大额滞纳金：高税额 × 长逾期 | 无（财务面全部一致） | 黄 | 76（−12×2） | 2 / 0 | 滞纳金公式：增值税 850×0.0005×97 天=41.225 万；企税汇算 600×0.0005×66 天=19.8 万；合计 61.025 万；仅申报维度扣分时的等级落点（黄而非红）；跨月逾期天数计算 |
