# PortfoTax · 投后财税雷达

PE/VC 投后被投企业财税一致性与申报监测工具（MVP 原型）

> 🏆 "AI智汇·财税创变" 参赛作品

## 快速开始

```bash
# 直接双击打开即可运行（零构建）
app/index.html
```

或者起本地服务（可选）：

```bash
cd app
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 核心功能

| 模块 | 说明 |
|------|------|
| 📊 组合总览 | 企业卡片墙、组合健康分、风险分布图、待申报提醒 |
| 🔍 一致性校验 | 6 条财税勾稽规则（三表勾稽、账税比对、发票匹配等），AI 风险解读 |
| 📅 申报日历 | 多税种申报期限管理、逾期预警、滞纳金估算 |
| 📋 体检报告 | 单企业月度财税报告，浏览器打印即 PDF |

## 演示数据

6 家虚构被投企业，覆盖绿色（健康）、黄色（关注）、红色（预警）三档风险等级。

## 技术栈

纯前端 · 零构建 · 原生 JavaScript · Tailwind CSS CDN · Hash 路由 SPA
