# PortfoTax · 投后财税雷达（Demo · V2.1）

> 主题：「AI智汇·财税创变」—— PE/VC 投后被投企业财税一致性与申报监测轻量级 Web 应用原型（demo 级）。

纯前端、零构建、无后端、无数据库、零外部依赖（不引入任何 CDN 库）。演示数据均为虚构。

**V2 新增**：CSV 数据导入（localStorage 持久化）、基准日动态化、规则参数化（#/settings 系统设置页）。
**V2.1 新增**：申报日历网格动态化——月份导航与默认月智能选择。

## 运行方式

- **最简单**：直接双击 `index.html`，用浏览器（Chrome / Edge）打开即可运行。
  全部脚本通过普通 `<script>` 标签加载（非 ES module），兼容 `file://` 协议。
- **或起本地服务**（可选）：
  ```bash
  cd app
  python -m http.server 8080
  # 浏览器访问 http://localhost:8080
  ```

## V2-1 CSV 数据导入

### 设计决策：两个 CSV，而非一个合并 CSV

财务科目是**宽表**（每企业一行，18 列），申报记录是**长表**（每企业每税种一行，6 列），
行粒度不同；合并成一个 CSV 会导致大量空列与企业信息重复，既难填又易错。
因此采用 **两个 CSV 文件** 的方案，导入面板支持 **Ctrl/Shift 一次多选两个文件**，
系统按表头自动识别类型；申报记录 CSV 可选（缺省视为暂无申报记录），但必须与财务科目 CSV 同批导入。

### 导入格式

**① 三表关键科目 CSV（必选，每企业一行）** —— 口径同 `test-data/import_template.csv`：

```
企业ID,企业名称,行业,轮次,地区,投资时间(YYYY-MM),账面营业收入(万元),增值税申报销售额(万元),开票金额(万元),净利润(万元),未分配利润_期初(万元),未分配利润_期末(万元),本期分红(万元),利润总额(万元),企税申报应纳税所得额(万元),销售商品收到现金(万元),工资总额(万元),社保个税申报基数(万元)
```

**② 申报记录 CSV（可选，每企业每税种一行）** —— 口径同 `test-data/import_template.xlsx` 的「申报记录」表：

```
企业ID,税种,所属期间,申报截止日(YYYY-MM-DD),"申报完成日(YYYY-MM-DD,未申报留空)",税额(万元)
```

> 第 5 列表头本身含逗号，规范 CSV 中会被引号包裹（Excel 另存为 CSV 时自动处理），解析器兼容。

- 金额单位：万元；日期格式 `YYYY-MM-DD`；所属期间格式 `YYYY-MM / YYYY-Qn / YYYY-FY`。
- 「申报完成日」留空表示未申报，系统按基准日自动判定 临期(≤3 天)/逾期 并估算滞纳金。
- 编码 UTF-8（兼容带 BOM）；字段含逗号/引号/换行时用双引号包裹，引号内 `"` 写作 `""`。
- Dashboard「下载财务科目模板 / 下载申报记录模板」按钮可下载内嵌生成的模板（带 BOM，Excel 直开不乱码）。
  **注意**：模板示例行的企业ID（yunqi / xinglian）与演示企业相同，导入前请替换为实际 ID，否则会触发「重复 ID」校验报错（属预期行为）。

### 校验与行为

- **行级校验**：表头错误 → 整文件拒绝；数据行错误（缺字段 / 非数字 / 非法日期 / 企业ID 重复或在财务表中不存在）→ 逐行报错并跳过该行，合法行正常导入。
- 导入企业与演示企业**同屏展示**，卡片带「导入」徽章与 **× 删除按钮**（单个删除）；导入面板提供「清除全部导入数据」。
- 导入数据保存在浏览器 **localStorage**（key 前缀 `portfotax.v2.`），刷新不丢失；localStorage 不可用时自动回落到会话级内存存储。

## V2-2 基准日动态化

- **演示企业**：默认固定按演示基准日 `2026-06-20` 评估（演示模式，结果稳定可复现）。
- **导入企业**：始终以**真实当天日期**为基准日评估。
- **设置开关**：`#/settings` 提供「用真实当前日期评估演示数据」（默认关）。开启后演示企业改按真实当天日期评估，逾期/临期状态随日期变化，属预期行为。
- UI 标注：Dashboard 页头与 KPI、企业卡片、企业详情、体检报告均标注当前评估基准日及来源（演示 / 实时 / 导入·实时）。

## V2-3 规则参数化（#/settings）

`rules.js` 全部阈值与权重已抽为 `Rules.DEFAULT_CONFIG`，`Rules.evaluateCompany(company, baseDate, config?)`
第三参数可选、支持部分覆盖（深合并）；**缺省配置下评估结果与 V1 完全一致（向后兼容）**。

设置页可调项（保存于 localStorage，可「恢复默认参数」，页面标注当前配置来源：默认/自定义）：

| 设置项 | 默认值 |
|---|---|
| R1 容忍度：差异率阈值 / 绝对容忍额（万元） | 3% / 0（不启用） |
| R2、R4 差异率阈值 | 5% |
| R3、R6 差异率阈值 | 10% |
| 严重度分档边界（各规则「中」「高」边界） | R1：5%/20%；R2、R4：5%/15%；R3、R6：10%/25% |
| R5 收现比正常区间 / 严重度「高」边界 | 0.7–1.3 / <0.5 或 >1.5 |
| 健康分扣分权重（高/中/低/逾期/临期） | 30/20/10/12/4 分 |

固定不变项：等级划分（绿 ≥ 90，黄 60–89，红 < 60）、临期窗口（≤3 天）、滞纳金率（万分之五/日）。

## V2.1 申报日历网格动态化（#/calendar）

V2 及之前日历网格固定展示演示期间所在月份（2026 年 6 月），真实日期远离该月时格内无条目。V2.1 改为动态网格：

- **月份导航**：网格上方「‹ 上一月 | YYYY 年 M 月 | 下一月 ›」切换控件（跨年安全）与「回到默认月」按钮，可浏览任意月份；各企业申报事项按真实截止日落在对应月份格子内，沿用 已申报/临期/逾期/未到期 状态着色。
- **默认月智能选择**：进入日历页默认展示「**最早的未申报截止日所在月份**」（最具行动价值）；若全部事项均已申报（或无申报事项），回退为**真实当前月份**。默认月随导入数据即时重算（导入企业的未申报截止日可能把默认月拉到更早月份）。
- **轻提示**：当前浏览月份与默认月不一致时，导航条右侧显示琥珀色徽章「当前浏览：YYYY 年 M 月（默认月：…）」；回到默认月后自动消失。离开日历页再进入时自动复位到默认月。
- **不变项**：风险提醒列表与状态统计仍为全量动态计算，不随浏览月份变化；状态判定沿用既有 baseFor 口径（演示企业 2026-06-20 / 导入企业真实当天），`rules.js` 评估逻辑零改动。
- 纯函数 `pickDefaultMonth(items, today)` 与 `shiftMonth(y, m, delta)` 经 `PortfoTaxApp._pickDefaultMonth / _shiftMonth` 导出，可直接 Node 单测。

## 规则引擎（js/rules.js）

纯函数设计，不依赖 DOM，可直接在 Node 中单测：

```bash
node -e "global.window={};require('./data/demo.js');require('./js/rules.js');\
console.log(window.Rules.evaluateCompany(window.DEMO.companies[4],'2026-06-20'))"
```

| 规则 | 名称 | 判定 | 默认阈值 |
|---|---|---|---|
| R1 | 三表勾稽 | 净利润 ≈ 未分配利润变动 + 分红 | 差异率 > 3%（可选绝对容忍额） |
| R2 | 账税一致性 | 账面营业收入 vs 增值税申报销售额 | 差异率 > 5% |
| R3 | 所得税匹配 | 利润总额 vs 企税应纳税所得额 | 差异率 > 10% |
| R4 | 发票-申报比对 | 开票金额 vs 增值税申报收入 | 差异率 > 5% |
| R5 | 现金流勾稽 | 收现比 = 销售收现 / 营业收入 | 超出 0.7–1.3 |
| R6 | 社保个税匹配 | 工资总额 vs 社保/个税申报基数 | 差异率 > 10% |

滞纳金估算：税额 × 0.05% × 逾期天数（《税收征管法》第三十二条口径，仅供演示）。
